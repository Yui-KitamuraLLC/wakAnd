# wakAnd v1.5.0 リリースノート

バージョンコード：22。公開日は公開後に記録します。

## 変更内容

- WakaTime公式のOAuth連携・再連携・解除に対応しました。外部ブラウザで認可し、アプリへ戻って連携します。
- ユーザー情報、プロジェクト取得、自動記録、手動時間登録をOAuthへ統合しました。
- WakaTimeと独自ホストをトグルで切り替えられます。独自ホストは保存済みのHTTPS API URL・APIキーを使用します。
- 認証失敗、権限不足、通信失敗、プロジェクト0件を区別して表示します。通信失敗だけで連携情報やアプリ設定を削除しません。
- 日英の状態表示・移行案内と、認証バックエンドを含むプライバシーポリシーを更新しました。

## 既存ユーザーの移行

1. アンインストールやデータ削除をせず、署名済みAPKで上書き更新してください。
2. 公式WakaTimeを利用する場合は、接続先をWakaTimeにして「WakaTime OAuth」から連携してください。ブラウザで許可後、アプリの連携状態を確認します。
3. 既存のアプリ別有効設定・プロジェクト割当・独自ホストURL/APIキーは保持します。接続先の切替だけではOAuthを解除しません。
4. 2026年11月1日のWakaTime認証制限変更に備え、OAuthへ移行してください。移行前の公式APIキーは自動活動送信だけを継続し、ユーザー情報・プロジェクト取得・手動登録にはOAuthが必要です。
5. OAuth解除・失効後はAPIキーへ自動で切り替えません。オフラインでの解除は端末の利用を停止し、提供元の失効を接続復帰後に再試行します。

## 動作要件・制限

- Android 10（API 29）以上。活動記録には使用状況アクセス、ブラウザURL記録にはユーザー補助の許可が必要です。
- WakaTime公式はWakaTimeアカウントとOAuth認可、独自ホストは接続先のAPIキーが必要です。
- オフライン中の活動を後からまとめて送るHeartbeatキューは未実装です。通信復帰後の新しい活動を送信します。
- 手動登録の送信結果が不明な場合は同じ画面・接続先・内容で再試行してください。新しい記録を作る前にダッシュボードで反映を確認してください。
- 独自ホストはAPIキー方式を維持し、自動試験で資格情報の分離を確認しました。実サーバーでの互換性は未検証です。

公開前の検収状態は[1.5.0検証記録](verification-1.5.0.md)で管理し、公開完了とは分けます。

# wakAnd v1.0 リリースノート（過去の記録）

**リリース日**: 2026年7月10日

## 初版リリース 🎉

WakaTime連携でAndroidのアプリ使用時間を自動トラッキングするクライアントアプリの初版リリースです。

---

## 主な機能

- **アプリ使用状況の自動トラッキング**: フォアグラウンドアプリを検出し、WakaTime APIへHeartbeatを自動送信
- **アプリ別トラッキング設定**: アプリごとにトラッキングのON/OFF切替、WakaTimeプロジェクト名の割り当てが可能
- **Chrome URL取得**: アクセシビリティサービスによりChromeで閲覧中のURLをHeartbeatのentityとして送信
- **WakaTimeユーザー情報表示**: 連携中のユーザー名表示とダッシュボードへのリンク
- **カスタムAPIエンドポイント対応**: WakaTime互換サーバー（Wakapi等）のURL設定に対応
- **日本語/英語切替**: アプリ内で表示言語を切替可能
- **常駐通知**: 現在トラッキング中のアプリ名を通知バーに表示（ON/OFF切替可能）
- **新規アプリインストール通知**: 新しいアプリのインストール時にトラッキング設定を促す通知を表示

## 動作要件

- Android 15（API 36）以上
- WakaTimeアカウント（APIキー）が必要
- 使用状況へのアクセス権限
- 通知権限

## 既知の制限事項

- オフライン時のHeartbeatキューイング・リトライは未実装
- WakaTimeダッシュボード・統計情報のアプリ内表示は非対応（Webダッシュボードをご利用ください）
